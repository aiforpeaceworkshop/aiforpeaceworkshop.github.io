## What this repository contains

This repository is the source for the AI for Peace workshop website. The home
page presents the second edition at NeurIPS 2026; `/first-edition` preserves the
ICLR 2026 workshop as an archive.

The site is a static React application built with Vite, TypeScript, and
Tailwind CSS. Its visual system extends the workshop’s original pixel wordmark
with hard edges, halftone shading, restrained red accents, and color portraits.
It deliberately avoids arcade animation, neon effects, and military stock
imagery.

Workshop facts, people, calls, dates, and references are centralized in
[`src/data/site.ts`](src/data/site.ts). The approved proposal and published call
are the sources of truth; the website should not introduce unsupported claims,
biographical details, or event information.

## Run locally

Requirements: Node.js 20 or newer and npm.

```bash
npm ci
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

Run the complete local preflight before publishing:

```bash
npm run check
```

This lints the source and creates the production build. The build writes a
physical `dist/first-edition/index.html` entry for the archive route and a
`dist/404.html` fallback for unknown client-side routes.

## Updating workshop content

Most editorial updates require changes only to
[`src/data/site.ts`](src/data/site.ts).

| Change | Data export |
| --- | --- |
| Workshop title, submission link, contact | `SITE` |
| Current venue, city, date, and format | `CURRENT_EDITION` |
| Announcement bar | `NEWS` |
| Workshop objectives | `OBJECTIVES` |
| Call topics and dates | `CFP_TOPICS`, `CFP_TIMELINE` |
| NeurIPS organizers | `ORGANIZERS` |
| NeurIPS invited speakers | `NEURIPS_SPEAKERS` |
| ICLR archive | `FIRST_EDITION_*` |
| Bibliography | `REFERENCES` |

Read the [content guide](docs/CONTENT.md) before changing names, affiliations,
talk topics, dates, references, or portraits. It includes the source hierarchy,
editorial rules, and verification checklist.

Portraits live in `public/img/speakers/` and `public/img/organizers/`. Prefer a
square image of at least 700 × 700 pixels from an official or recoverable
source. Do not upscale small images or use search-result thumbnails.

## Wordmark workflow

`public/img/aiforpeace_logo.png` is the untouched source artwork. The site uses
optimized transparent masks generated by
[`scripts/generate_logo.py`](scripts/generate_logo.py). The script preserves
the original letter geometry and halftone, and generates Pac-Man shading from
the same measured angle and pattern.

After changing the source artwork or generator:

```bash
python3 scripts/generate_logo.py
npm run check
```

Never substitute the wordmark with text, trace it into a simplified logo, or
use it as the favicon. See the [design guide](docs/DESIGN.md) for the visual
rules.

## Deployment

A push to `master` runs
[`.github/workflows/deploy.yml`](.github/workflows/deploy.yml). The workflow
installs dependencies with `npm ci`, builds the static site, and publishes
`dist/` through GitHub Pages.

Repository setting required:

```text
Settings → Pages → Build and deployment → Source: GitHub Actions
```

Use the [quality checklist](docs/QUALITY.md) before release and the
[deployment guide](docs/DEPLOYMENT.md) for the full publishing procedure and
troubleshooting.
